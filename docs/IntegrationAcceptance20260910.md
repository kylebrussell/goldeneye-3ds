## Reproducible private packaging

`docs/acceptance/candidate-template.json` covers every roadmap row. Copy it into
a private evidence directory, recording actual test artifacts, environments,
results and bounded scopes. Pending rows must retain concrete remaining work.
Physical evidence needs a device identity; emulator/host results cannot pass a
physical gate. Fidelity needs matched reference evidence.

After committing source changes, run:

```sh
python3 scripts/build_3ds_candidate.py --output build/integration/release-build \
  --toolchain devkitpro/devkitarm@sha256:116afba8df8453961de2936ffab20dd441edf4d682856c1ec8b0e53d7ed0bbf5
python3 scripts/package_3ds_candidate.py \
  --binaries build/integration/release-build/binaries --pack build/3ds-assets/goldeneye.u.gepack \
  --build-receipt build/integration/release-build/build-receipt.json \
  --acceptance build/integration/acceptance.json --evidence build/integration \
  --toolchain devkitpro/devkitarm@sha256:116afba8df8453961de2936ffab20dd441edf4d682856c1ec8b0e53d7ed0bbf5 \
  --output build/integration/candidate
python3 scripts/package_3ds_candidate.py --verify build/integration/candidate
```

Add `--settings DIRECTORY` only for an explicit directory containing
`controls.cfg` and/or `stereo.cfg`. Omitted files use the candidate's compiled
defaults. No save files, probe configs, replay routes or world-profile overrides
are staged. Pack textures are self-contained; the entire pack is hashed.

The build receipt binds committed source, immutable toolchain image, successful
force-build log and exact binary hashes. The package inventories the executable,
metadata, pack, settings, evidence and receipt. Verification detects added,
removed or changed files and rejects symlinks. Source converter hashes are
recorded explicitly as the candidate's converter versions; copying an existing
pack does **not** prove it was regenerated by those versions. `--require-complete`
adds a failing gate for every unfinished roadmap row. Hashes provide integrity
and identity, not cryptographic authenticity or proof that an observation is true.
